OpenAIのGPT-5.5・GPT-5.4・CodexがAmazon Bedrockで一般提供開始

FEAT AWS What's New · 2026/6/1
要約: GPT-5.5・GPT-5.4・CodexがAmazon Bedrockで本番利用可能（GA）に。IAM・PrivateLink・KMS・CloudTrailなど既存のAWSガバナンス統制をそのまま適用でき、プロンプトはOpenAIへ共有されない。料金はOpenAI直接利用と同一で追加手数料なし。CodexはVS Code・JetBrainsなどIDEから利用可能。

新機能の背景

AWS と OpenAI は 2026 年 5 月に拡大パートナーシップを発表し、その約 1 ヶ月後に GPT-5.5・GPT-5.4・Codex が Amazon Bedrock 上で一般利用可能（GA）となりました。

企業が OpenAI のフロンティアモデルを活用したいというニーズが高まる一方、IAM・VPC/PrivateLink・KMS 暗号化・AWS CloudTrail による監査ログといった既存の AWS セキュリティ・ガバナンス基盤をそのまま適用したいという要望も増えていました。OpenAI モデルを直接利用する場合、データ主権の確保や企業内ガバナンスポリシーとの整合に課題が生じることがあります。

Amazon Bedrock が OpenAI モデルの推論基盤となることで、プロンプトや応答がモデルプロバイダー（OpenAI）に共有されたりモデルのトレーニングに使用されたりすることなく、既存の AWS ガバナンス統制（IAM 権限管理・PrivateLink 分離・KMS 暗号化・CloudTrail 監査）を OpenAI モデルにもそのまま適用できるようになります。これにより、セキュリティ・コンプライアンス要件の厳しいエンタープライズ環境でも、OpenAI の最先端モデルを安心して本番利用できます。

新機能の概要

Amazon Bedrock のモデルカタログに、以下の OpenAI モデルが追加されました。

利用可能なモデル

モデル 概要 主なユースケース
GPT-5.5 OpenAI 最高性能のフロンティアモデル エージェント的コーディング、データ分析、複数ステップの自律タスク
GPT-5.4 優れた価格対性能比を持つフロンティアモデル 複雑なビジネスシステムを横断した推論・ツール利用・コンピュータ操作
GPT OSS 120B 1,200 億パラメータのオープンソース汎用モデル テキスト生成・コーディング・推論
GPT OSS 20B 200 億パラメータの軽量オープンソースモデル 低コストでの効率的なテキスト生成・コーディング
GPT OSS Safeguard 120B コンテンツモデレーション用セーフティモデル（120B） AI アプリのガードレール・コンテンツ審査
GPT OSS Safeguard 20B コンテンツモデレーション用セーフティモデル（20B） 軽量なコンテンツモデレーション・ガードレールタスク

Codex — AI コーディングエージェント

Codex は OpenAI が提供する AI コーディングエージェントで、毎週 500 万人以上の開発者が利用しています。リポジトリ全体にわたってコードの記述・リファクタリング・デバッグ・テスト・検証を行い、複雑なシステム間の依存関係を理解しながら変更を伝播させます。GPT-5.5 で推論を行うことで、従来のモデルバージョンより効率的かつ高品質にタスクを完了します。

Codex は以下のクライアントから利用でき、すべての推論を Amazon Bedrock 経由にルーティング可能です。

  • Codex App（デスクトップアプリ）
  • Codex CLI（コマンドラインツール）
  • IDE 統合：Visual Studio Code・JetBrains・Xcode

推論エンジンと料金

  • 推論エンジン：Bedrock の次世代推論エンジン（内部名：Mantle）上で動作。自動キャパシティ管理・耐障害性（リクエスト途中のハードウェア障害からの再開）・分離キューを提供します。
  • 料金：OpenAI 直接利用と同一のトークン単価。追加手数料なし。シートライセンスや開発者単位のコミットメント不要。既存の AWS コミットメント（EDP 等）に対して利用量を充当可能。
  • API：OpenAI の Responses API 互換エンドポイント（bedrock-mantle.<region>.api.aws/openai/v1）を通じて呼び出します。

使い方

1. GPT-5.5 / GPT-5.4 を Python SDK から呼び出す

まず OpenAI Python SDK をインストールします。

pip install -U openai

Bedrock エンドポイントと API キーを環境変数に設定します（Bedrock API キーは AWS コンソールまたは CLI で発行）。

export OPENAI_BASE_URL="https://bedrock-mantle.us-east-2.api.aws/openai/v1"
export OPENAI_API_KEY="<BEDROCK_API_KEY>"
export BEDROCK_OPENAI_MODEL_ID="openai.gpt-5.5"

OpenAI SDK を使って GPT-5.5 を呼び出すサンプルコードです。

import os
from openai import OpenAI

client = OpenAI(
    base_url=os.environ["OPENAI_BASE_URL"],
    api_key=os.environ["OPENAI_API_KEY"],
)

response = client.responses.create(
    model=os.environ["BEDROCK_OPENAI_MODEL_ID"],
    input=[
        {
            "role": "developer",
            "content": "You are a software engineer with excellent AWS cloud knowledge. Be concise and practical.",
        },
        {
            "role": "user",
            "content": "Design a distributed architecture on AWS that supports 100k requests per second across multiple geographic regions.",
        },
    ],
    reasoning={"effort": "medium"},
    text={"verbosity": "low"},
)

print(response.output_text)

curl での呼び出しも可能です。

curl "$OPENAI_BASE_URL/responses" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -d '{
    "model": "openai.gpt-5.5",
    "input": [
      {
        "role": "developer",
        "content": "You are a software engineer with excellent AWS cloud knowledge."
      },
      {
        "role": "user",
        "content": "Design a distributed architecture on AWS that supports 100k requests per second."
      }
    ],
    "reasoning": {"effort": "medium"},
    "text": {"verbosity": "low"}
  }'

2. Codex を Amazon Bedrock 経由で使う

Codex は Bedrock API キー、または AWS SDK クレデンシャルチェーン の 2 通りで認証できます。API キーを使う場合は以下のように設定します。

① 環境変数にAPIキーを設定

export AWS_BEARER_TOKEN_BEDROCK=<your-bedrock-api-key>

② ~/.codex/config.toml でモデルとリージョンを設定

model = "openai.gpt-5.5"
model_provider = "amazon-bedrock"

[model_providers.amazon-bedrock.aws]
region = "us-east-2"

gpt-5.4・gpt-oss-120b・gpt-oss-20b も同様に指定可能です。デスクトップアプリや VS Code 拡張機能は ~/.codex/config.toml または ~/.codex/.env を変更した後に再起動が必要です。

Codex CLI を使う場合は /status タブで Bedrock 経由の推論が確認できます。

注意点

  1. リージョン制限（2026年6月時点）：GPT-5.5 は米国東部（オハイオ: us-east-2）のみ、GPT-5.4 は**米国東部（オハイオ）と米国西部（オレゴン: us-west-2）**で利用可能。今後のリージョン拡大は AWS リージョンページ を確認してください。

  2. 推論レイテンシは設定次第で大きく変わる：GPT-5.5 は高速・GPT-5.4 は中程度とされますが、実際の体感レイテンシは推論エフォート（reasoning.effort）・出力長・ツールコール数・バックグラウンドモード・リージョン・クォータ・スロットリング・プロンプトサイズ・キャッシュヒットに依存します。

  3. 推論エフォートの初期値：GPT-5.5 は medium エフォートから始めることを推奨。GPT-5.4 はデフォルトが none のため、品質を確保するには reasoning={"effort": "low"} など明示的にエフォートを指定することが推奨されます。

  4. 高負荷時はキューイング：需要が急増してもリクエストは拒否されずキューに積まれます。既存の安定ワークロードが優先されるため、急激なトラフィックスパイク時は応答が遅延する場合があります。

  5. データプライバシーの保証範囲：プロンプトおよびレスポンスはモデルのトレーニングに使用されず、OpenAI を含むモデルプロバイダーとも共有されません。ただし、AWS サービス全般の利用規約および Bedrock サービス規約の範囲内での保証となります。

  6. Codex の認証優先順位：AWS_BEARER_TOKEN_BEDROCK 環境変数が設定されている場合はそちらが優先され、未設定の場合は AWS SDK クレデンシャルチェーン（~/.aws/credentials、IAM ロール等）にフォールバックします。API キー認証を使う場合は ~/.codex/config.toml でのモデル ID 設定が必須です。
