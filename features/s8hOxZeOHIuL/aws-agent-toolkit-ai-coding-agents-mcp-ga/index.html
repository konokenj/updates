AWS、Agent Toolkit for AWSを一般提供開始 — AIコーディングエージェントのAWS構築を支援する本番対応ツールスイート

FEAT AWS What's New · 2026/5/6
要約: AIコーディングエージェントがAWSで効果的に構築できるよう支援する本番対応ツールスイート。エージェントスキル・AWS MCPサーバー・プラグインの3コンポーネントで構成。エラー削減・トークンコスト低減・IAMガバナンスを実現。AWS LabsのMCPサーバー群の後継製品。

新機能の背景

AIコーディングエージェントをAWSでの開発に活用する開発者は、近年次のような深刻な課題に直面していました。

  • マルチサービスワークフローの複雑さ：複数のAWSサービスを組み合わせた複雑なワークフローで、エージェントが適切に対応しきれず、誤ったAPI呼び出しや試行錯誤を繰り返してしまう。
  • 古い知識への依存：基盤モデルのトレーニングデータは数ヶ月〜数年前のものであるため、Amazon S3 Tables・Aurora DSQL・Bedrock AgentCoreなど新しいサービスや機能についての知識が欠落している。
  • ガバナンスの困難さ：エージェントがローカル端末でAWSコマンドを実行する場合、エージェントの操作と人間の操作を区別できず、組織全体のポリシーを適用したり、アクティビティを監査することが事実上不可能だった。
  • トークンコストの増大：ベストプラクティスを知らないエージェントが試行錯誤を繰り返すことで、不要なAPIコールが大量発生し、トークンコストが膨らんでいた。

これらの問題を解決するために、AWSは本番環境対応の統合ツールスイートである Agent Toolkit for AWS を開発・リリースしました。なお、本ツールキットはAWS Labsで提供されてきたMCPサーバー・スキル・プラグイン群の正式な後継製品として位置づけられています。

新機能の概要

Agent Toolkit for AWSは、AIコーディングエージェントがAWSサービスを使って効果的に構築・デプロイ・運用できるよう支援する、3つの主要コンポーネントから構成された本番対応ツールスイートです。

1. エージェントスキル（Agent Skills）

特定のAWSタスクをエージェントが正確・確実に完了するための、キュレートされた手順書・コードスクリプト・参考資料のパッケージです。エージェントが一般知識に頼って即興で対応するのではなく、AWSのベストプラクティスに沿った検証済み手順を辿れるようにします。

  • サービス選択ガイド：特定ユースケースに最適なAWSサービスを選ぶための推奨事項とトレードオフ分析
  • ステップバイステップ手順：S3 Tablesの作成、Glue ETLパイプラインのセットアップ、IAMポリシーの設定、サーバーレスアプリケーションのデプロイなど、代表的なタスクの実証済みワークフロー
  • トラブルシューティングガイド：一般的なエラーの診断手順と根本原因分析・解決ステップ
  • オンデマンド読み込み：スキルはタスクに応じてその都度読み込まれるため、コンテキストウィンドウの使用量を最小限に抑えられる

今回の発表では、IaC・ストレージ・アナリティクス・サーバーレス・コンテナ・AIサービスを対象とした 40以上のスキル が公開されました。今後はデータベース・ネットワーキング・IAM向けスキルも追加予定です。

2. AWS MCPサーバー（AWS MCP Server）

AIエージェントがModel Context Protocol（MCP）経由でAWSに安全にアクセスできるようにする、フルマネージド型リモートサーバーです。今回のリリースで一般提供（GA）となりました。

機能 詳細
完全なAWS APIカバレッジ 300以上のAWSサービス・15,000以上のAPIアクションに対応。AWS CLIをローカルにインストール不要
サンドボックス実行環境 Pythonスクリプトをローカルのファイルシステムやネットワークにアクセスせず隔離された環境で実行可能
リアルタイムドキュメント検索 最新のAWSドキュメント・APIリファレンス・サービス機能を認証なしで検索・取得
エンタープライズ制御 IAMコンテキストキー（aws:CalledViaAWSMCP）によるエージェント専用ポリシーの適用、CloudWatchメトリクスとCloudTrail監査ログ

3. エージェントプラグイン（Agent Plugins）

AWS MCPサーバーの設定と厳選されたスキルセットを 1回のインストールでまとめて導入 できる簡易パッケージです。

プラグイン 対象ユーザー・用途
aws-core アプリケーション開発者向け。サービス選択・CDK/CloudFormation・サーバーレス・コンテナ・ストレージ・オブザーバビリティ・デプロイメント等
aws-agents AIエンジニア向け。Amazon Bedrock AgentCoreを使った本番対応AIエージェントの構築
aws-data-analytics データエンジニア・BIエンジニア向け。S3 Tables・AWS Glue・Athenaを使ったデータパイプラインの構築・運用

現在Claude CodeとCodexに対応しており、今後他のエージェントへのサポートも拡張予定です。

使い方

前提条件

  • uv のインストールが必要（MCPプロキシの動作に必要）
  • APIコール・スクリプト実行にはAWSアカウントとローカルに設定済みのIAM認証情報が必要（ドキュメント検索・スキル探索は認証情報なしで利用可能）

Claude Code の場合

/plugin marketplace add aws/agent-toolkit-for-aws
/plugin install aws-core@agent-toolkit-for-aws
/reload-plugins

追加プラグインのインストール例：

/plugin install aws-agents@agent-toolkit-for-aws
/plugin install aws-data-analytics@agent-toolkit-for-aws

Codex の場合

ターミナルで以下を実行後、Codexを起動して /plugins コマンドからインストールします。

codex plugin marketplace add aws/agent-toolkit-for-aws

プラグイン非対応エージェントの場合

エージェントのMCP設定ファイル（例：Kiro CLIなら ~/.kiro/settings/mcp.json）に以下を追記します。

{
  "mcpServers": {
    "aws": {
      "command": "uvx",
      "args": ["mcp-proxy-for-aws@latest", "https://mcp.us-east-1.amazonaws.com"]
    }
  }
}

スキルはCLIから個別に追加することも可能です。

npx skills add aws/agent-toolkit-for-aws

インストール後、新しい会話を開始して以下のように質問することで接続を確認できます。

AWSリージョンの一覧が返ってきたら接続成功です。認証エラーが出る場合はユーザーガイドのトラブルシューティングを参照してください。

エージェントは関連スキルをリクエスト内容から自動的に検出・使用するため、ユーザーが個別のスキルを把握・指定する必要はありません。

注意点

  • 料金について：Agent Toolkit for AWS自体は追加料金なしで利用可能です。エージェントがプロビジョニング・操作するAWSリソースに対しては、通常のAWS料金が発生します。

  • AWS Labsとの関係：AWS LabsのMCPサーバー・スキル・プラグインは引き続き利用可能で、コントリビューションも受け付けます。ただし今後はAgent Toolkit for AWSへの移行が推奨されており、AWS Labsの優れたツールは段階的にAgent Toolkit for AWSへ統合されていく予定です。既存のAWS Labsユーザーはすぐに移行を迫られるわけではありませんが、新機能・新スキルはAgent Toolkit for AWS側で優先的に提供されます。

  • IAMポリシーの設計：IAMコンテキストキー aws:CalledViaAWSMCP を活用することで、「MCPサーバー経由のエージェント操作だけ読み取り専用に制限する」など、エージェントの行動にのみ適用される細かいポリシーを作成できます。既存のIAMロールに広い権限がある場合でも、エージェント経由のアクションを安全にスコープ制限できます。

  • スキルのカバレッジ：今回提供されるのはIaC・ストレージ・アナリティクス・サーバーレス・コンテナ・AIサービスを対象とした40以上のスキルです。データベース・ネットワーキング・IAM向けスキルは今後追加予定であるため、これらの領域での利用は現時点では限定的な場合があります。

  • 対応エージェント：プラグインによるワンクリックインストールは現在Claude CodeとCodexに対応。Cursor等の他エージェントはMCPサーバーを直接設定する方法で利用可能です。スキルのみの利用であればMCP対応の任意のエージェントで使えます。
