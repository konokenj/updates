Amazon EC2 G7インスタンスが一般提供開始 — NVIDIA RTX PRO 4500 Blackwell GPU搭載でG6比最大4.6倍のAI推論性能を実現

FEAT AWS What's New · 2026/6/18
要約: NVIDIA RTX PRO 4500 Blackwell GPU搭載のEC2 G7インスタンスが一般提供開始。G6比で最大4.6倍のAI推論性能・最大2.1倍のグラフィックス性能を実現。最大700 Gbps EFAネットワーク対応。言語翻訳・動画解析・音声認識・ゲームストリーミングなどのGPUワークロードに最適。

新機能の背景

生成AIや大規模言語モデル（LLM）の普及に伴い、クラウド上でのAIインファレンス需要が急速に拡大しています。また、リアルタイムグラフィックス・動画解析・空間コンピューティングといったGPU集約型ワークロードも多様化しており、前世代のG6インスタンス（NVIDIA L4 Tensor Core GPU搭載）では対応しきれないケースが増えてきていました。

G6インスタンスはG4dnと比べ2倍の性能を実現しましたが、5th Gen Tensor Coreや大容量GPU メモリ、超高速EFAネットワーキングへの要求が高まる中、より高い世代のGPUアーキテクチャが必要とされていました。

今回、AWSは主要クラウドプロバイダーとして世界初でNVIDIA RTX PRO 4500 Blackwell Server Edition GPUをサポートし、G7インスタンスとして一般提供を開始しました。G6と比較して最大4.6倍のAIインファレンス性能と最大2.1倍のグラフィックス性能を実現し、次世代のGPUワークロードに対応します。

新機能の概要

Amazon EC2 G7インスタンスは、NVIDIA RTX PRO 4500 Blackwell Server Edition GPUとカスタムIntel Xeon 6プロセッサを搭載した、AIインファレンス・グラフィックス・データ分析ワークロード向けの高性能GPUアクセラレーテッドインスタンスです。

使い方

利用開始方法

G7インスタンスは以下のいずれかの方法で起動できます。

  1. AWS Management Console：Amazon EC2コンソールからインスタンスタイプに g7.* を選択して起動
  2. AWS CLI：aws ec2 run-instances --instance-type g7.2xlarge ... のように指定
  3. AWS SDK：各言語のSDKから InstanceType に g7.* を指定

推奨AMI・セットアップ手順

ユースケース 推奨AMI・方法
AIインファレンス全般 AWS Deep Learning AMIs (DLAMI)（GPUドライバー・フレームワーク同梱）
グラフィックスワークロード NVIDIA Workstation AMIs（NVIDIAドライバー事前インストール済み）
コンテナ（Kubernetes） Amazon EKS + NVIDIA driver R595でのEKS AMIビルド
コンテナ（ECS） Amazon ECSでのGPU対応タスク定義
HPCワークロード AWS PCS（Slurm）との組み合わせ

利用可能リージョン

現時点では以下の2リージョンで利用可能です。

  • US East (Ohio) （us-east-2）
  • US West (Oregon) （us-west-2）

今後のリージョン展開は AWS Capabilities by Region ページのCloudFormationリソースタブで確認できます。

注意点

  • g7.metal は近日公開：ベアメタルサイズ（g7.metal）は現時点では「Coming soon」ステータスのため、ベアメタルが必要なワークロードはリリースを待つ必要があります。
  • 提供リージョンは限定的：一般提供開始時点では US East (Ohio) と US West (Oregon) の2リージョンのみです。東京リージョンなど他リージョンへの展開時期は未発表のため、日本国内のレイテンシが重要なシステムでは引き続き利用計画の検討が必要です。
  • Amazon SageMaker AI 統合は近日公開：SageMaker AIとのマネージド統合は「coming soon」とされており、現時点ではDLAMIやEKS/ECSを使った自己管理でのデプロイが必要です。
  • Amazon EKSで利用する場合はNVIDIAドライバーのバージョンに注意：EKSで使用するには NVIDIA driver version R595 でEKS AMIをビルドする必要があります。標準のEKS最適化AMIには含まれていない場合があるため、EKS提供の自動化スクリプトを使用してください。
  • Dedicated Instancesのサポートはサイズ限定：専有インスタンスは g7.12xlarge・g7.24xlarge・g7.48xlarge のみ対応しています。コンプライアンス要件でDedicated Instancesが必須の場合は対応サイズを事前に確認してください。
  • G6との互換性：G7インスタンスのGPUドライバー（NVIDIA R595系）はG6（L4 GPU向けドライバー）と異なる場合があります。既存G6ワークロードの移行時はAMIやドライバーの対応確認が必要です。
  • 料金情報：詳細な料金はAWSが公式に更新する Amazon EC2料金ページ を参照してください。G7はG6より高性能である分、料金単価も高くなる可能性があります。Savings Plansやスポットインスタンスの活用でコスト最適化を検討してください。
