Amazon SageMaker JumpStartにFLUX.2-klein-base-4BとQwen3-Embedding-0.6Bが追加

FEAT AWS What's New · 2026/5/14
要約: SageMaker JumpStartに画像生成モデルFLUX.2-klein-base-4B（Black Forest Labs）とテキスト埋め込みモデルQwen3-Embedding-0.6B（Qwen）が追加。前者は4Bパラメータのコンパクト設計でリアルタイム画像生成を実現し、後者は100言語以上に対応したセマンティック検索・RAGパイプライン構築を支援する。

新機能の背景

企業が生成 AI を活用するうえで、「高品質な画像生成」と「高精度なテキスト検索・意味理解」はそれぞれ異なる基盤モデルを必要とします。従来、これらのモデルを AWS 上で利用するには、コンテナのセットアップやインフラの管理など多くの作業が伴いました。また、高性能な画像生成モデルの多くは大規模な GPU を前提とするため、コスト面での障壁もありました。

一方、多言語環境でのセマンティック検索や RAG（Retrieval-Augmented Generation）パイプラインの構築には、100 言語以上に対応した高精度なテキスト埋め込みモデルが不可欠ですが、品質・速度・対応言語の三拍子そろった選択肢は限られていました。

Amazon SageMaker JumpStart はこうした課題に対応するため、主要プロバイダーの最先端基盤モデルをカタログへ継続的に追加しています。今回、Black Forest Labs の FLUX.2-klein-base-4B（画像生成）と Qwen の Qwen3-Embedding-0.6B（テキスト埋め込み）が新たに追加され、クリエイティブ AI アプリケーションとインテリジェント検索システムの構築がより手軽になりました。

新機能の概要

FLUX.2-klein-base-4B（画像生成）

Black Forest Labs が開発した FLUX.2-klein-base-4B は、4B パラメータのコンパクトなアーキテクチャでリアルタイム画像生成とマルチリファレンス編集を実現するモデルです。

特徴 詳細
モデル規模 4B パラメータのコンパクト設計
動作環境 最小 13GB VRAM のコンシューマー向け GPU で動作可能
主要機能 リアルタイム画像生成、マルチリファレンス編集
主なユースケース クリエイティブコンテンツパイプライン、商品ビジュアライゼーション、ラピッドプロトタイピング、高品質画像合成

Stable Diffusion XL など従来の画像生成モデルと比較して、FLUX.2-klein-base-4B はコンパクトな設計でありながら最先端の品質を維持し、13GB VRAM という低いハードウェア要件でも動作します。

Qwen3-Embedding-0.6B（テキスト埋め込み）

Qwen が開発した Qwen3-Embedding-0.6B は、100 言語以上に対応した高精度なテキスト埋め込みモデルです。

特徴 詳細
対応言語数 100 言語以上
主要機能 テキスト検索・分類・クラスタリング・バイテキストマイニング
柔軟性 可変出力次元、インストラクション対応埋め込み
主なユースケース セマンティック検索システム、RAG パイプライン、多言語ドキュメント検索、大規模テキスト表現生成

インストラクション対応（instruction-aware）埋め込みと可変出力次元のサポートにより、タスク固有のファインチューニングなしに検索・分類・クラスタリングなど多様なタスクへ適用できます。

使い方

① Amazon SageMaker Studio から利用する（GUIベース）

  1. SageMaker Studio を開き、左パネルの Models を選択、または Home ページの Explore models をクリック
  2. 検索バーで FLUX.2-klein-base-4B または Qwen3-Embedding-0.6B を検索
  3. モデルの詳細カードを開き、右上の Deploy ボタンをクリックしてデプロイワークフローを開始
  4. インスタンスタイプ等を設定し、デプロイが完了したらエンドポイントを通じて推論リクエストを送信

② SageMaker Python SDK から利用する（コードベース）

from sagemaker.jumpstart.model import JumpStartModel

# --- FLUX.2-klein-base-4B（画像生成）の例 ---
image_model = JumpStartModel(model_id="<flux2-klein-base-4b-model-id>")
image_predictor = image_model.deploy()
response = image_predictor.predict({"prompt": "a photorealistic mountain landscape at sunset"})

# --- Qwen3-Embedding-0.6B（テキスト埋め込み）の例 ---
embed_model = JumpStartModel(model_id="<qwen3-embedding-0.6b-model-id>")
embed_predictor = embed_model.deploy()
embeddings = embed_predictor.predict({"inputs": "検索対象のテキストをここに入力"})

モデル ID の確認方法: SageMaker Studio のカタログページ、または sagemaker SDK の list_jumpstart_models() を使って正確なモデル ID を取得してください。

③ 他の AWS サービスとの連携例

連携サービス 連携内容
Amazon OpenSearch Service Qwen3-Embedding-0.6B の埋め込みベクトルを格納し、kNN ベクトル検索を構築
Amazon Bedrock Knowledge Bases RAG パイプラインの埋め込みモデルとして Qwen3-Embedding-0.6B を利用

注意点

  • ライセンスの必須確認: FLUX.2-klein-base-4B は Black Forest Labs、Qwen3-Embedding-0.6B は Qwen のライセンス条件が適用されます。商用利用の可否・再配布制限など、利用前に必ずライセンス内容を確認してください。AWS はサードパーティコンテンツのライセンス遵守についてユーザーの責任としています。
  • ハードウェア（インスタンス）要件: FLUX.2-klein-base-4B はローカル環境では最小 13GB VRAM が必要です。SageMaker へのデプロイ時は適切な GPU インスタンスタイプ（例: ml.g5.2xlarge 以上）を選択してください。インスタンスタイプによってコストが大きく異なるため、SageMaker 料金ページ を事前に確認することを推奨します。
  • モデル ID の正確な確認: SageMaker JumpStart のモデル ID はバージョンや地域によって異なる場合があります。Studio のカタログまたは SDK のモデル一覧で最新の正確なモデル ID を使用してください。
  • リージョン対応状況: JumpStart の新規追加モデルは、すべての AWS リージョンで同時に利用可能とは限りません。デプロイ予定のリージョンでの可用性を事前に確認してください。
  • カタログ変更リスク: 2026年3月13日以降、JumpStart ではカタログの品質向上のため一部モデルが削除されています。既存のエンドポイントは引き続き動作しますが、カタログは今後も定期的に更新される可能性があります。本番環境では特定モデルへの依存度に注意し、代替モデルの選択肢を把握しておくことを推奨します。
  • 料金体系: SageMaker JumpStart 自体の追加料金は発生しませんが、デプロイ先の SageMaker エンドポイント（EC2 インスタンス）の利用時間に対して課金されます。使用しない際はエンドポイントを削除するか、オートスケーリングの設定を行ってください。
